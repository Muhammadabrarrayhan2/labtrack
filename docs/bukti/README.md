# Folder Bukti Tangkapan Layar

Satu subfolder per unit kompetensi. Setiap subfolder memiliki `README.md` berisi daftar bukti yang harus diambil, dengan kode yang sama seperti di `docs/00-PEMETAAN-UNIT-KOMPETENSI.md`.

Aturan pengambilan bukti:

1. Simpan dengan nama `<kode>.png`, misalnya `B-014-03.png`. Bukti berupa berkas teks atau CSV memakai nama yang tertulis di daftar.
2. Pastikan project ID, URL, atau nama resource terlihat, dan sertakan jam sistem atau stempel waktu konsol bila memungkinkan. Hal ini mendukung prinsip Asli dan Terkini.
3. Jangan menampilkan password, token JWT, atau isi secret. Samarkan bila tidak sengaja terlihat.
4. Centang kolom "Sudah" setelah berkas tersimpan.
